fix: 模型下拉只显示勾选、联系人卡片缺少"开始分析"按钮

模型徽标下拉（#modelBadgeMenu）里每一行只剩一个 ✓，配置名和模型名都不显示，
本地模型那一行则变成一条空的、可点击却没有任何内容的行。

根因是 DOM API 误用：`appendChild` 是单节点方法，多余参数会被静默忽略。
`button.appendChild(tick, body)` 只插入了 tick，整个文字容器 body 被丢弃，
于是 name/model 从未进入 DOM。改为 `append`（variadic）即可，共4 处调用
（modelBadgeOption 与 localModelBadgeOption 各两处）。

联系人卡片新增"开始分析"按钮，位于姓名左侧：
- 只有点击过的联系人才会被分析，并进入后台分析名单；未点击的既不触发分析，
  也不会出现在名单里
- 请求名单与"已添加的会话"分开保存（chatState.requestedConversations），
  把会话加入列表不等于请求分析它
- 点击立即分析该联系人，不依赖"后台分析"开关；后台扫描只遍历请求名单
- 按钮有未点击/已加入两种状态，再点一次可移出名单
- 点击不冒泡，不会顺带切换会话

原backgroundAnalyzeAll 里的本地分支与 API 分支合并为 analyzeConversations，
两种模型来源走同一套提交逻辑，避免两边漂移。

模型行的 name/model 必须真正入树）、tests/conversation-analyze-button.test.cjs
