# WechatVibe 1.2.4 发布说明

本版让 API 人物画像只按选项打分，由程序归一化，不再因分数加总或多余分支中断整批。修复思考模型的连接测试和设置窗口尺寸，并加入更新提示、本地并行分析，以及会话列表的过滤与添加。

## 下载内容

| 文件 | 用途 |
| --- | --- |
| `WechatVibe-1.2.4-windows-x64.zip` | Windows x64 标准应用包，不内置模型 |
| `WechatVibe-1.2.4-source.zip` | 本版源码、测试与公开文档 |
| `WechatVibe-diagnose.bat` | 可单独下载、重复使用的启动诊断工具 |
| `update-manifest.json`、`update-manifest.sig` | 应用内更新所需的清单与签名 |
| `SHA256SUMS.txt` | 标准包、更新清单及签名的 SHA-256 校验值 |

下载入口：[v1.2.4 Release](https://github.com/tswawa/WechatVibe/releases/tag/v1.2.4)。运行时请保留整个 `win-unpacked` 目录，双击其中的 `WechatVibe.exe`。

Laya 继续作为独立的 `WechatVibe-Laya-model-v1.zip` 提供，模型文件不变。已有模型无需重新下载；只使用 API 时无需安装本地模型。

## API 人物画像

模型不再交回必须凑齐条数、加总为 1 的概率数组。它按每个选项的标签给出 0-100 的相对分数，可以只写大于 0 的选项，分数不必加总为 100。程序把这些分数归一化，再沿用本地 Laya 的路由和累计。

少写的选项视为 0，多写的标签忽略，加总不是 1 或 100 不再失败。多猜的条件分支被忽略。模型漏答、条数不对或没有正分的条件分支，按本地路由跳过这一支，保留其余分支，不改用另一支，也不再追问。每批聊天只调用一次模型。必答的基础题仍要有可读的正分；若当前选中的分支全部无法使用，这一批仍会失败，且不会借用未选中的分支。

回复在长度上限被截断时，界面提示「模型输出达到长度上限被截断」。除 Anthropic 必须填写输出上限外，这次判断不设输出上限。格式错误最多重试 2 次；网络错误仍最多重试 10 次。单次判断最长等待 240 秒。

## 连接测试与设置窗口

「测试连接」不再给思考模型设置很小的输出上限。除 Anthropic 仍限制 128 tokens 外，探测不设输出上限，推理占用的 token 不会再把这次测试判失败。网关仍按自己的默认上限截断时，测试视为已经连通。

设置窗口在各个标签页、本地部署和 API 接入下保持同一尺寸：宽 650、高 680。屏幕较小时窗口缩小，较长的设置在窗口内滚动。

## 更新提示

软件在启动约 10 秒后静默检查更新，之后每 6 小时检查一次。没有新版本或检查失败时不打扰。发现可安装的新版本后，左下角设置按钮上方显示「更新」，点击打开「设置 → 关于 → 软件更新」。

1.2.3 以及更早的已安装版本没有这个提示。这些用户仍在「设置 → 关于 → 当前版本」里检查更新。

## 本地分析与会话列表

这些改动来自 silicon-sbt 的拉取请求，并按现有设置和侧边栏做了调整。

- **并行分析**：本地模型可以同时分析多路会话，默认 1 路，最多 4 路。并行数和「跟随负载」放在「设置 → 通用设置」的本地模型设置中。开启后，同时运行的路数随机器负载升降；关闭后按设定路数固定运行，不再继续采样。
- **服务号与系统会话**：服务号和系统会话不再进入会话列表。文件传输助手、普通联系人和群聊仍会列出。
- **全部添加**：在「设置 → 通用设置 → 信息列表」中点击「全部添加」，把当前会话加入侧边栏。首次启动不会自动填满。手动移除的会话保持移除。点过「全部添加」之后，只有从未出现过的新会话会自动加入。
- **进度与后台分析**：「后台分析已添加的会话」默认关闭，关闭时侧边栏保持安静。开启后，对已添加的会话做本地分析，会话列表下方显示整账号进度，说明里包含并行档位。`GET /api/analysis-overview` 与 `GET /api/analysis-performance` 只读返回进度和耗时，不能用来改写分析状态。

## 升级

1. 1.2.3 用户在「设置 → 关于 → 当前版本」检查更新。标准应用包会保留已有数据、配置和独立模型。左下角「更新」提示从 1.2.4 起才有，1.2.3 里不会出现。
2. 已下载的 Laya 模型继续使用，不必重新下载。只使用 API 时不需要模型包。
3. 1.0.4 的旧更新器仍不支持新版标准包，请手动下载。完全退出旧版后覆盖应用文件，保留 `resources/client/.local` 和 `resources/client/.models`，不要先删除旧软件目录。
