# WechatVibe 1.3.5

本次更新整合了外部 PR 中经复核的能力，并加入三个回复选项、可控分析范围和多实例支持，同时修复本地分析在切换模型来源后无响应的问题。

### 新增

- **多 API 模型档案**：可保存、测试、启用、切换、编辑和删除多个 API 配置。各档案分别保存密钥和分析结果身份，切回原模型恢复对应结果；只改名称不会清空已有结果，真正更换正在使用的密钥才会取消旧凭据任务。
- **可控分析范围**：添加会话与请求分析分开保存，浏览会话不会自动开启整段分析。顶部「意图识别」开启后处理当前已加载的有效对方文本，并接续新消息；滚动和窗口大小不会缩小范围，不自动加载更早历史。手选消息只把选中的几条作为分析目标，周围消息仍作为上下文。
- **单条重新分析**：右键单条文本即可重新测评。使用独立任务状态，返回相同结果也能正常结束；旧后台任务晚回来不会覆盖刚重算的消息。
- **三个回复选项**：选择 API 模型并在助手仓库启用助手后，点击原沟通建议图标生成三行候选回复。继承当前选中聊天助手的提示词和 Skills，按当前会话上下文一次生成三条可直接发给对方的候选；再次点击会重新调用模型并替换三条。点击文本即复制，不自动发送到微信。
- **多实例**：源码启动 `npm start -- --profile account-b`，已打包客户端使用 `WechatVibe.exe --profile account-b`。不同实例可选择不同已登录账号，模型选择、端口与窗口数据隔离；只有默认实例提供更新入口。
- **MBTI 四轴展示**：四轴独立计分，有有效分数即显示对应比例，未知轴不填 50/50。100 条解锁、每轴证据数和倾向差距仍约束人格字母，避免因单条行为强行定型。

### 优化与修复

- **本地分析状态**：修复模型切换、首次准备和已有结果恢复时点击识别无响应的问题，恢复本地模型名称、入口与画像进度更新。窗口内消息全部已有有效结果时给出完成反馈，不重复推理。
- **本地意图判断**：改善具体改期、聊天收尾、句中求助、条件同意和建议的漏标，修正陈述、转述与否定的误判；普通确认和证据不足内容仍留白。旧本地细标签按新规则刷新，已有画像与 API 标签保留。
- **读取与统计**：账号切换期的短暂读取失败两秒后可重试，扫描预算等持续性失败保留长退避。统计按历史结果与批次证据完整恢复，保留旧 API 画像显示及有效证据计数。
- **API 并发**：设置中共享分析并行数可设为 1–4（默认 1），画像和连接探测各有独立槽位。连续两次限流降低共享并发，连续八次成功后恢复到设置上限；实际收益取决于服务方。
- **桌面模型下载**：中断后再次下载可复用已收到的部分；服务不支持 Range 时安全重新下载，校验完整后才安装。已下载完整但安装失败的文件可直接重试安装。
- **分析结果加密**：分析结果列采用 AES-GCM 加密并由 Windows DPAPI 保护密钥，首次打开每个结果库时建立一致性恢复备份。密钥缺失、截断、换 Windows 用户或密文损坏会明确报错并保留数据，不伪装成空画像，也不自动换新密钥继续写入。

### 使用与升级

- **标准应用包**：`WechatVibe-1.3.5-windows-x64.zip`，不内置 Laya 模型。解压后运行 `win-unpacked/WechatVibe.exe`，并保留完整目录。
- **源码包**：`WechatVibe-1.3.5-source.zip`，包含本版源码、测试和公开文档。
- **已有模型**：继续使用 `WechatVibe-Laya-model-v1.zip`，已有 Laya 模型无需重新下载。仅使用 API 或聊天助手时无需下载 Laya。
- **升级入口**：在「设置 → 关于 → 当前版本」检查更新。升级保留账号数据、分析结果、画像、助手配置及已下载模型。1.3.0 可直接应用内更新到本版。
- **加密边界**：加密范围是分析结果列，不是整个聊天库、助手历史或所有文件。旧明文行仍兼容读取，并在下一次写入时加密；不会自动重写全部历史或抹去磁盘残留。若要回退到不支持该加密格式的旧版本，需要另行验证整个安装与全部数据的一致性备份。
- **回复选项的上下文**：候选生成使用一次模型请求，不启用助手工具、文件写入或记忆修改。上下文预算包含助手提示词、Skills 和相关参考资料；4k 配置下长技能或长消息仍可能放不下，不足时会报实际错误，不会静默丢弃助手设定。
