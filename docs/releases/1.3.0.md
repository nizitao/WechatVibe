# WechatVibe 1.3.0

本次更新新增助手仓库和只读聊天助手，支持导入助手、在固定面板中交流，并改善会话管理、分析恢复和启动提示。

### 新增

- **助手仓库**：左侧新增助手入口，可启用、编辑和删除助手。已有助手支持修改名称、说明、欢迎语、提示词及选用技能。
- **导入助手**：「新建助手」直接进入导入窗口，支持 GitHub 地址、本地 `SKILL.md`、技能目录和 ZIP。预览后可修改内容，需要只读适配时由用户确认；重复导入同来源、同版本会保留已有助手的编辑和对话。
- **聊天助手**：聊天工具栏新增「聊天助手」，在主窗口内的固定宽度右侧面板中查看回答。助手结合当前会话提供交流建议、内容整理和回复草稿，回答逐步显示；草稿不会自动发送到微信。
- **独立对话**：助手记录、草稿和已生成内容按微信账号、会话、助手分别保存。支持停止和失败重试；输入 `/reset` 只重置当前助手对话，保留聊天记录、消息分析和画像。
- **批量移除会话**：管理会话时已添加项排在前面，可勾选后点击「移除所选」，每次最多 1000 个。移除只改变列表选择，聊天、画像和助手记录保留。
- **局部重置分析**：聊天页新增「重置会话分析」，清除当前来源的消息标签和该会话全部画像；画像页新增「重置画像」，只重置当前对象或群成员的画像。两种操作均保留其他会话、其他来源和助手记录；重置单个成员画像时保留该群其他成员的结果。

### 优化与修复

- **API 人物画像**：继续沿用本地 Laya 的累计和计分规则，保存进度并在新消息到来后续算。改善切换会话、模型来源和群成员时的结果恢复，减少重复处理。
- **分析恢复**：分析状态异常时显示可理解的重试提示，并提供会话或画像重置入口。重置期间停止对应范围的写入，避免已清除的结果被旧任务写回。
- **账号准备提示**：区分账号尚未就绪和资料准备中的状态，显示对应提示与重试入口，减少长时间停留在笼统的失败提示上。
- **本地分析**：减少重复分词计算，限制缓存大小，并在账号切换或缓存清理时释放保留的文本。整体耗时仍主要取决于模型推理，本项不代表明显的端到端加速。
- **退出与重启**：改善本地服务和后台进程的归属识别与回收，关闭或重启当前客户端时保留其他客户端实例。
- 修复清除账号后聊天助手记录或缓存仍残留的问题。

### 使用与升级

- **助手模型**：聊天助手使用设置中保存的生成式 API 或 Ollama 兼容连接，模型需要支持工具调用。本地 Laya 继续用于消息和画像分析，不生成助手回答。
- **只读范围**：助手仅能读取本轮提供的当前会话资料和选用技能文本，不能发送微信消息、执行命令、修改文件或访问其他会话资料。导入包内的脚本、插件和外部工具能力不会执行。使用助手时，相关资料和提问会按需要发送到所配置的模型服务。
- **旧 API 画像**：旧格式画像仍先保留显示。首次点击「更新画像」时需要按新规则重建一次，会重新处理对应历史并产生 API 请求；之后继续分析新消息，切换页面或重启不会反复重建。
- **标准应用包**：`WechatVibe-1.3.0-windows-x64.zip`，不内置 Laya 模型。解压后运行 `win-unpacked/WechatVibe.exe`，并保留完整目录。
- **源码包**：`WechatVibe-1.3.0-source.zip`，包含本版源码、测试和公开文档。
- **已有模型**：继续使用 `WechatVibe-Laya-model-v1.zip`，已有 Laya 模型无需重新下载。仅使用 API 或聊天助手时无需下载 Laya。
- **升级入口**：在「设置 → 关于 → 当前版本」检查更新。升级保留账号数据、分析结果、画像、助手配置及已下载模型。
